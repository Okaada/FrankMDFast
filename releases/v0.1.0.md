First release of FrankMD as a native desktop app, rewritten in Rust with GPUI.

It is a drop-in replacement for the Rails FrankMD: it reads the same `.fed` file and environment
variables and works on the same folder of notes, so you can switch between the two.

## Highlights

- Markdown editor with live preview, math, syntax highlighting, tables, tasks and wikilinks
- Vim mode, typewriter mode, find and replace, command palette (Ctrl+Shift+P) and quick open (Ctrl+P)
- Hugo blog posts, image and video embedding (local folder or S3), YouTube and image search
- AI grammar check and image generation with OpenAI, Anthropic, Gemini, OpenRouter or Ollama
- Follows the Omarchy theme and language live; 18 built-in themes
- Settings for every option, including interface size (80–200%)

## Security changes compared with FrankMD

- Uploads must really be images or videos (content is checked, not just the extension)
- URLs with `user:password@` are refused
- The AI grammar check never sends `.fed` or secrets
- Search, backlinks and media scans never follow links out of the notes folder

## Downloads

| System | File |
|---|---|
| Linux x86_64 / aarch64 | `FrankMD-0.1.0-<arch>.AppImage` or `frankmd-0.1.0-linux-<arch>.tar.gz` |
| Arch Linux | `yay -S frankmd-bin` |
| macOS (Apple Silicon and Intel) | `FrankMD-0.1.0-macos-universal.dmg` (signed and notarized) |
| Windows x86_64 | `FrankMD-0.1.0-windows-x86_64-setup.exe` or the portable zip |

The Windows build is not code-signed yet, so SmartScreen will ask before the first run.
Check downloads against `SHA256SUMS`.

## Known gaps

Relative line numbers, right-to-left layout for Hebrew, settings "Test connection" buttons and a
keyring for secrets are not done yet. On Windows a second launch opens a new window instead of
reusing the running app.
