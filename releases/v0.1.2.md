FrankMDFast 0.1.2 makes ⌘ shortcuts work across the app on macOS.

## Fixed

- macOS: every shortcut now answers to ⌘ as well as Ctrl — ⌘P, ⌘S, ⌘B, ⌘⇧P, ⌘W, … — contributed
  by @Okaada (#5). Ctrl keeps working everywhere and Linux/Windows behavior is unchanged.
- macOS: the media and grammar dialogs accept ⌘↵ and ⌘1–⌘7; the delete-confirmation dialog accepts
  ⌘↵ and the explorer's select-all accepts ⌘A.
- Shortcut labels (command palette, help, status-bar chip, empty-state hints, dialog buttons) now
  derive from one table and print ⌘⇧P style on macOS; the note switcher shows ⌃Tab because ⌘Tab
  belongs to the macOS app switcher.
- The macOS app menu's key equivalents show ⌘ (for example ⌘Q) instead of ⌃.
