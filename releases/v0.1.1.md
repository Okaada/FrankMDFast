FrankMDFast 0.1.1 fixes note and folder creation on Windows and the basic macOS window
behavior reported against 0.1.0.

## Fixed

- Windows: creating notes and folders works again (#1). Vault operations joined paths with `/`
  onto the canonicalized notes root, which Windows reports as a verbatim `\\?\` path; verbatim
  paths reject `/`, so every create, open, save, rename and delete failed with the generic
  "Failed to create". Paths are joined with `\` there now, and the Windows CI job runs the note
  and folder flow on a real filesystem so it cannot return silently.
- Windows and Linux with client-side decorations: the window has a title bar with close,
  minimize and maximize buttons and a drag area, instead of no controls at all.
- macOS: the sidebar header no longer sits underneath the traffic-light buttons (#2).
- macOS: clicking the Dock, Launchpad or Finder icon after closing the window with the red
  button reopens the window instead of doing nothing while the process keeps running (#3).
- macOS: ⌘Q quits the app, through a proper app menu; the shortcut help that showed ⌘Q now
  matches the key that actually works (#4).
