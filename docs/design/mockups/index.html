FrankMDFast UI reference

Static mockups for the GPUI + gpui-component build. Icons are Phosphor (regular) from assets/icons/phosphor.json, the logo is assets/brand/icon.svg, and built-in theme swatches come from assets/themes/builtin.json. Every app colour comes from a real Omarchy colors.toml, mapped through the roles in ui-spec.md §7. A few text and syntax colours in the light themes and Everforest are already contrast-corrected to 4.5:1, as §7.1 requires. Corners follow Hyprland's decoration:rounding: 0 on stock Omarchy, 6 with rounded corners on. Frames are drawn at 1:1 logical pixels.
